About

I work on systems that turn models and data into dependable products.

I am a software engineer interested in distributed computing, data infrastructure, ML platforms, and the emerging systems around AI agents.

The throughline

Data infrastructure → ML platforms → agent infrastructure

These fields belong to different technology cycles, but they share hard questions: how to define boundaries, manage state, trace data and behavior, evaluate real outcomes, and understand failures.

I turn those recurring engineering questions into articles, experiments, and runnable code so that design judgments become public and testable.
