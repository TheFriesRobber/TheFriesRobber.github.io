关于

我关注如何把模型和数据变成可靠的产品系统。

我是一名软件工程师，长期关注广告数据、分布式计算、OLAP、feature store 和 ML pipelines；最近一年也开始探索 AI Agent 相关系统。

贯穿始终的主线

数据基础设施 → ML Platform → Agent 基础设施

这些领域看起来属于不同技术周期，但核心问题很相似：如何定义边界、管理状态、追踪数据与行为、评估系统是否真的有效，以及在故障发生时知道发生了什么。

我希望把这些领域里共通的工程问题整理出来，通过文章、实验和可运行的代码，将设计判断变成可以被检验和讨论的公开记录。
